# Multi-Level Secure Image and Text Encryption

## 📌 Overview

This project is a secure web-based application designed to protect
text and image data using multiple layers of encryption and
steganography.

## 🎯 Objective

The main objective is to provide secure communication by combining
cryptographic techniques with image steganography.

## 🛠️ Technologies Used

- Python
- Flask
- Hill Cipher
- DES Encryption
- Steganography
- HTML
- CSS

## 🔐 Key Features

- Secure text encryption
- Image encryption
- Multi-level security
- Steganographic data hiding
- Web-based user interface
- Secure decryption process

## 🔄 Working Process

1. User enters a secret message.
2. The message is encrypted using cryptographic techniques.
3. The encrypted data is embedded into an image using steganography.
4. The protected image can be transferred securely.
5. The receiver extracts and decrypts the hidden message.
